# 理念索引与结构设计入口

本目录承载结构设计的判断原则。README 只负责问题入口和内容路由；具体原则各有唯一归属，
不要把展开内容继续堆回总览。

## 内容归属约定

- 每条原则只有一个事实来源；README 和 checklist 只链接，不复制解释。
- 抽象原则进入本目录，真实 case 进入 [examples](examples/README.md)。
- 新内容先按模型、边界、演进、可维护性选择 owner；找不到归属时先调整结构，不新增“其它”章节。
